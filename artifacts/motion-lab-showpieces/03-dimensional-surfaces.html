holo-card

Spring-tracked 3D tilt with specular glare and iridescent foil

Flagship
MOTIQ OPEN PASS
128components · all free
M-0128-2607 MIT · SINCE 2026

move pointer to tilt · drag on touch · arrow keys when focused

Niche

Tilt cards are the most-installed component class on every animated catalog — they turn a static pricing tier, membership pass, or team card into an object people want to touch. The holo variant earns the hero slot on landing pages and account screens, where one card carries the brand's entire material feel.

Choreography

  1. Idle sway — before any input, tilt targets follow sin(0.5t)·4° / cos(0.37t)·3°, so the foil moves on load.
  2. Track — pointer offset maps to targets rotateX ±11°, rotateY ±15°; two springs (k=120, d=10, ζ≈0.46) chase them, so tracking lags ~80ms with a soft elastic feel.
  3. Light — glare hotspot and foil conic origin are pinned to the raw pointer (no smoothing: light is instant, mass is not); foil hue rotates 4°/deg of rotateY plus 40° across the card's width.
  4. Counter-shadow — ground shadow translates opposite the tilt (−1.8px/deg) and dilates ~8% at full lean.
  5. Release — targets return to the idle sway; the underdamped spring overshoots ≈6% once before settling (~600ms).

Props API

interface HoloCardProps {
  children: React.ReactNode
  maxTilt?: number          // deg, default 14
  spring?: { stiffness: number; damping: number }
  foil?: "azure" | "spectral" | "none"
  glare?: boolean           // default true
  shadow?: boolean          // counter-moving ground shadow
  idleSway?: boolean        // ambient motion before hover
  onTilt?: (rx: number, ry: number) => void
}

A11y & Perf

  • Reduced motion: fixed −6°/8° tilt with a static foil — still dimensional, zero movement.
  • Keyboard: card is focusable; arrow keys nudge tilt targets ±4° per press.
  • Touch: pointer events + touch-action: none on the card only, so the page still scrolls.
  • GPU: transform-only motion; foil/glare are pre-painted layers whose custom properties move gradient origins — no repaints of card content.
  • Single rAF loop, delta-time clamped at 50ms; IntersectionObserver parks it offscreen.

hover the panel — the comets accelerate

Niche

The border beam is the modern "look here" affordance — changelog highlights, featured plans, active integrations. It adds motion to a container without touching its layout or content, which is why it is one of the most copied effects on product marketing sites.

Choreography

  1. Ring construction — a rotating conic gradient sits behind a 2px ring cut with a two-layer CSS alpha mask (mask-composite: exclude). No SVG luminance masks — those silently no-op in Chromium.
  2. Twin comets — one azure→cyan comet and one coral comet 180° apart, each a ~45° tail easing into a 4° bright head. The coral head is this page's single signature-color moment.
  3. Idle orbit — angular velocity rests at 42°/s (~8.5s per lap). A blurred copy of the same gradient sits behind the panel at 35% opacity as cast light.
  4. Hover surge — velocity itself is sprung (k=30, d=11) toward 240°/s on pointerenter, so the comets wind up and coast down instead of snapping between speeds.

Props API

interface BorderBeamPanelProps {
  children: React.ReactNode
  beams?: 1 | 2              // default 2, opposed
  colors?: [string, string?]
  thickness?: number       // px, default 2
  idleSpeed?: number       // deg/s, default 42
  hoverSpeed?: number      // deg/s, default 240
  glow?: boolean           // blurred cast light
  radius?: number          // px, default 16
}

A11y & Perf

  • Reduced motion: orbit freezes at 40° with both comets visible — reads as a lit border, not a broken one.
  • Decorative layers are aria-hidden and pointer-events: none; content semantics untouched.
  • Only one custom property (--beam-a) changes per frame; the conic gradient re-rasterizes on the compositor-backed ring layer, content never repaints.
  • rAF loop is per-panel and IO-paused; velocity spring uses delta-time so tab jank never skips the beam ahead.
03

card-stack-deck

A physical deck — the top card arcs, flips, and tucks to the back

Interactive

click or drag the front card · arrow keys when focused

Niche

Stacked decks compress a set — testimonials, templates, categories — into one card's footprint and make browsing feel like handling objects. Product sites use them where a carousel would feel flat: onboarding tips, feature tours, gallery teasers.

Choreography

  1. Rest fan — five cards at continuous slot p: y = −18p px, z = −62p px, scale = 1 − 0.05p, rotateZ = 2.2p°, with a dim overlay fading in 0.14/slot. preserve-3d lets the browser depth-sort — no z-index management.
  2. Send — click, drag past ±90px, or ArrowRight retargets the front card's slot spring 0→4 (k=90, d=12). Progress q = p/4 drives the signature arc: x = sin(qπ)·210px, z-lift = sin(qπ)·150px, rotateY = q·360° — the card swings out, shows its patterned back at the apex, and lands face-up behind the deck.
  3. Ripple — the other four cards spring one slot forward on the same constants, arriving ~120ms after the send starts.
  4. Drag — a separate offset spring carries pointer delta (with rotateZ = dx·0.06°); on release below threshold it snaps home at k=200, d=16.
  5. Idle — the front card breathes: ±2px bob and ±0.7° sway on slow sines.

Props API

interface CardStackDeckProps {
  items: React.ReactNode[]
  cardBack?: React.ReactNode   // shown mid-flip
  fan?: { y: number; z: number; rotate: number }
  arcWidth?: number         // px, default 210
  spring?: { stiffness: number; damping: number }
  dragToShuffle?: boolean   // default true
  loop?: boolean
  onTopChange?: (index: number) => void
}

A11y & Perf

  • Keyboard: deck is a focusable group; ArrowRight/ArrowLeft (and the visible buttons) shuffle both directions.
  • An aria-live="polite" region announces the new front card after every shuffle.
  • Reduced motion: cards reorder instantly with no arc or flip; the fan itself stays as static depth.
  • Transforms only — the depth dim is an opacity overlay, not a filter, because filters would flatten preserve-3d.
  • One rAF loop for all five cards; springs sleep when every card is within 0.001 of target.

move pointer — each pane refracts at its own depth

Niche

Glassmorphism only convinces when something moves behind the glass. This panel pairs frosted layers with a live scene and depth-ranked parallax, which is what hero sections, pricing overlays, and OS-style widgets need to feel physical rather than like a blurred PNG.

Choreography

  1. Scene — five gradient orbs drift on lissajous paths on a DPR-aware canvas; additive blending in dark, soft alpha in light. Palette is read from tokens at runtime and re-read on theme change.
  2. Refraction — each glass layer is backdrop-filter: blur(16px) saturate(1.45) with a 1px specular top edge and an inner floor shadow.
  3. Parallax — pointer position drives per-layer offsets at depths 9 / 16 / 26px, each on a critically damped spring (k=110, d=21, ζ≈1.0) — near panes travel further, selling true separation. Idle: targets follow a slow lissajous so the stack never freezes.
  4. Entrance streak — on first viewport entry (and again on re-entry) a rotated specular band sweeps the main pane in 950ms, delayed 180ms so it reads as light, not load-in.

Props API

interface GlassRefractionPanelProps {
  children: React.ReactNode
  layers?: { node: React.ReactNode; depth: number }[]
  scene?: "orbs" | "custom" | "none"
  blur?: number            // px, default 16
  parallax?: number        // depth multiplier, 0 disables
  streakOnEnter?: boolean  // default true
  tint?: string            // glass fill override
}

A11y & Perf

  • Reduced motion: one static orb frame is painted, parallax and streak are disabled — the glass treatment itself carries the design.
  • Canvas is aria-hidden; all real content lives in the DOM layers with normal semantics and focus order.
  • Canvas re-themes via a prefers-color-scheme listener plus a MutationObserver on data-theme.
  • Layer motion is translate3d-only; blur cost is paid once per layer by the compositor, and the scene canvas is capped at 2× DPR.
  • IO pauses the orb loop offscreen; the streak runs as a one-shot CSS animation, not in JS.

3.4 kB gzip Canvas 2D rm-safe

hover the roof — the aurora leans toward the pointer

Niche

Full-page auroras are everywhere; a card that carries its own sky is not. Scoping the effect to a header band gives feature cards, changelog entries, and plan tiles a premium "live" quality without fighting page backgrounds — and several roofs can coexist on one grid.

Choreography

  1. Ribbons — three bands, each the sum of two sines (wavelengths ~340/210px, speeds 0.10–0.23 rad/s), filled with a vertical azure→cyan→transparent gradient. Additive lighter compositing in dark; saturated source-over strokes on a pale sky in light.
  2. Finish — the canvas is drawn crisp, then softened by a single GPU CSS blur(9px) at 116% scale (edges hidden); a generated noise tile overlays at 40% with overlay blending for grain.
  3. Lean — pointer x over the roof retargets a lean spring (k=50, d=14, ζ≈0.99); lean shifts each ribbon's phase by up to 90px and raises amplitude ~20%, weighted more on nearer ribbons. On leave it relaxes home over ~700ms.
  4. Stars — 40 static points shimmer on individual sine phases, dark theme only.

Props API

interface AuroraPanelProps {
  children: React.ReactNode    // card body
  height?: number          // roof px, default 210
  ribbons?: number         // 2-5, default 3
  colors?: string[]        // defaults to theme azure/cyan
  lean?: boolean           // pointer lean, default true
  grain?: number           // 0-1 opacity, default 0.4
  speed?: number           // time multiplier
  overlay?: React.ReactNode    // badge slot on the roof
}

A11y & Perf

  • Reduced motion: a single hand-tuned frame is painted and the loop never starts — the roof reads as a still sky photo.
  • Roof canvas and grain are decorative and aria-hidden; card content below is plain DOM.
  • Ribbon paths sample every 8px (~60 points each) — trivial per frame; the expensive blur is CSS, done once on the compositor.
  • Theme swap re-reads token colors and the sky fill live (media listener + MutationObserver); grain tile regenerates only on demand.
  • IO pauses drawing offscreen; touch-action: pan-y keeps mobile scroll intact over the roof.
