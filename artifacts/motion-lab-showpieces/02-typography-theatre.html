01 decrypt-text

scramble · staggered lock-in · terminal variant

Ship interfaces that feel alive. Terminal: motiq add decrypt-text — resolved in 84 ms.

$ 
hover the stage to re-encrypt

Niche

The reveal every dev-tool and security product wants: copy arrives like it is being decoded, which reads as "engineering happened here". Used on hero headlines, changelog titles and empty-state easter eggs.

The terminal variant doubles as a CLI onboarding flourish — perfect for install commands.

Choreography

  • t=0 every glyph is already scrambling — the line boils from the first frame.
  • Each unlocked char cycles a random pool glyph every 45–80ms (per-char jitter, never in sync).
  • Char i locks at 350 + i·55ms ± 120ms — a ragged left-to-right resolve, not a metronome.
  • Lock-in: real glyph snaps in with a 420ms accent flash + glow decay, ease (.2,0,0,1).
  • Auto re-runs every 7s while on screen; hover re-triggers with a 1.5s cooldown.

Props API

interface DecryptTextProps {
  text: string;
  glyphs?: string;   // scramble pool
  speed?: number;    // cycle ms · 45
  stagger?: number;  // lock ms · 55
  trigger?: "mount" | "hover"
          | "inview";
  variant?: "display" | "terminal";
  loop?: number | false;
  onDecrypted?: () => void;
}

A11y & perf

  • Animated glyphs live in an aria-hidden layer; the real string sits in a visually-hidden sibling, so screen readers never hear the scramble.
  • prefers-reduced-motion: text renders resolved, replay becomes a no-op.
  • Only textContent + color change per glyph — zero layout writes; single rAF loop, paused by IntersectionObserver offscreen.

02 proximity-type

variable weight · pointer gravity · idle breathing

Gravity has a typeface.

move the pointer — or a finger — through the line

Niche

The "touch the product" moment for type-led brands: the headline physically leans toward the cursor, so the first thing a visitor plays with is your copy. Ideal for portfolio heroes, font-adjacent tools and 404 pages people screenshot.

Rides the variable axes already shipped in SF Pro and Segoe UI — no font download.

Choreography

  • Per char: distance to pointer → falloff t = smoothstep(1 − d/180px).
  • Targets: font-weight 340 → 900, letter-spacing 0 → .06em, glow alpha 0 → .5, color lerped fg → accent.
  • Weights chase targets with exponential smoothing 1 − e^(−14·dt) — the lag is the gravity.
  • Idle (2s without pointer): a weight wave 430 ± 170 travels the line at ~0.5 char/frame, phase offset 0.5rad/char — the type breathes.

Props API

interface ProximityTypeProps {
  text: string;
  radius?: number;      // px · 180
  weightRange?: [number, number];
  spacing?: string;     // max · ".06em"
  glow?: boolean;
  idleWave?: boolean;
  falloff?: "smooth" | "linear";
  as?: "h1" | "h2" | "p";
}

A11y & perf

  • Real string in a visually-hidden node; the per-char layer is aria-hidden and unselectable.
  • Reduced motion: static weight 430, listeners never attach.
  • font-weight is layout-affecting by design — cost is bounded to one short line; char centers are cached and refreshed on resize/scroll, never read mid-frame.
  • Pointer Events cover mouse + touch; loop pauses offscreen.

03 split-flap

mechanical flips · column stagger · auto-rotating pages

Motiq terminal — departureslive

pages rotate every 6s

Niche

Physical-media nostalgia that modern dashboards keep reaching for: status walls, ticker strips, conference agendas, "now shipping" marquees. The mechanical flutter makes plain data feel like an arrivals hall.

Reads equally well at ticker size (one row) or as a full board.

Choreography

  • Each cell steps through the charset in order to its target — like real drums, max 14 steps via shortest forward distance.
  • One flip = 80ms: top flap rotateX 0 → −90°, then bottom flap 90° → 0, 320px perspective.
  • Final flip runs 150ms with a back-ease overshoot — the flap slaps past flat and settles.
  • Page stagger: col·38 + row·110 ± 90ms — a wave that sweeps the board.
  • Fast runs get 0.7px blur on the moving flap only; idle cells twitch randomly every ~1.4s.

Props API

interface SplitFlapProps {
  pages: string[][];  // rows per page
  cols?: number;
  interval?: number;   // ms · 6000
  flipMs?: number;     // · 80
  stagger?: { col: number;
    row: number; jitter: number };
  charset?: string;
  flutter?: boolean;
  onPage?: (i: number) => void;
}

A11y & perf

  • The board is aria-hidden; a polite aria-live region announces each settled page as one sentence.
  • Reduced motion: pages swap as instant text — content still rotates, nothing flips.
  • Flaps animate transform only (GPU-composited); glyph text is written at flip boundaries, never per frame. One rAF drives all 88 cells; offscreen = fully parked.

04 liquid-fill-headline

rising fill · sloshing meniscus · shimmer sweep

Set it in motion.

Set it in motion Set it in motion Set it in motion Set it in motion

tap the headline to re-pour

Niche

The progress-as-theatre headline: product launches, waitlist pages, funding meters, loading states that deserve a hero. An outlined wordmark filling with liquid is an instant focal point without a single image asset.

Motiq angle: it is pure CSS-clipped text — recolors itself with the theme for free.

Choreography

  • Two gradient text layers behind an outline; each is clipped by a 24-point clip-path polygon rebuilt per frame — the polygon is the wave.
  • Rise: level 108% → −6% over 3s ease-in-out; two sines (f, 1.7f) at phase speeds 3.1 / −4.3 rad/s make the slosh non-repeating.
  • Back layer runs 3.5% higher, phase-shifted — depth between the two surfaces.
  • Settle 0.8s: amplitude decays to 0. Then a 1s coral-white shimmer sweeps 120% → −20% — the page's one coral moment.
  • Hold 1.4s, drain 1s ease-in, loop. Tap restarts.

Props API

interface LiquidFillProps {
  text: string;
  fillMs?: number;    // · 3000
  holdMs?: number;
  amplitude?: number; // % · 4.5
  gradient?: string[];
  shimmer?: boolean;
  loop?: boolean;
  level?: number;     // controlled 0–1
  trigger?: "inview" | "manual";
}

A11y & perf

  • All four text layers sit under one aria-hidden stack; the real string is visually-hidden beside it.
  • Reduced motion: renders fully filled, no loop — still a handsome gradient headline.
  • Uses clip-path alpha clipping, not SVG luminance masks (gradient luminance masks silently no-op in Chromium).
  • Two clip-path writes + one background-position write per frame; pauses offscreen.

05 word-cascade

per-word springs · line orchestration · viewport trigger

Every launch deserves an entrance. Motiq's cascade drops each word into place with its own weight — a beat of blur, a breath of overshoot — until the line settles like it rehearsed. Wire it to the viewport and your hero copy directs itself.

Every launch deserves an entrance.

Motiq's cascade drops each word into place with its own weight — a beat of blur, a breath of overshoot — until the line settles like it rehearsed. Wire it to the viewport and your hero copy directs itself.

Niche

The premium hero-copy entrance every SaaS landing ships: heading first, body copy following in directed waves. It upgrades the ubiquitous "fade up on scroll" into something with weight and rhythm — the words feel cast, not printed.

Works on any block of markup: headings, paragraphs, list items.

Choreography

  • Words are measured into visual lines after layout; delay = line·150 + wordInLine·40ms.
  • Each word runs its own spring (k=180, c=16, dt-integrated) on progress s: 0 → 1 — underdamped, ~6% overshoot.
  • Mapped: y = −44px·(1−s) (falls past rest, bounces back), rotation ±7° · (1−s) random per word, blur 8px → 0, opacity keyed to first 40%.
  • Trigger: IntersectionObserver at 40% visible; re-arms after the block fully leaves; manual replay resets springs and re-measures.

Props API

interface WordCascadeProps {
  children: ReactNode;
  lineStagger?: number; // · 150
  wordStagger?: number; // · 40
  stiffness?: number;   // · 180
  damping?: number;     // · 16
  fromY?: number;  blur?: number;
  rotate?: number;     // max deg
  replayOnReenter?: boolean;
  onSettled?: () => void;
}

A11y & perf

  • Animated copy is aria-hidden; the full passage lives in a visually-hidden block, so reading order and selection stay intact for AT.
  • Reduced motion: words render in place instantly, replay is inert.
  • Springs write transform / opacity / filter only; blur is dropped the moment s ≥ 1 and will-change is cleared after settle. Line measurement happens once per (re)play, never per frame.
